# NOVA 💎 — מעקב הוצאות והכנסות אישי

אפליקציית ווב לניהול ומעקב אחר הוצאות והכנסות מהבנק וכרטיסי האשראי, בהשראת Rise Up,
בעיצוב dark-mode טכנולוגי עם זוהר ניאון.
**קריאה בלבד** — האפליקציה לא מבצעת פעולות בחשבון, רק מציגה ומנתחת נתונים.

> 🔒 **פרטיות**: זוהי אפליקציית **צד-לקוח בלבד** (אתר סטטי). כל הנתונים נשמרים
> ב-IndexedDB של הדפדפן **על המכשיר שלך** ולא נשלחים לשום שרת. אפשר לארח אותה בחינם
> ולגשת מכל מקום, והמידע הפיננסי נשאר פרטי לחלוטין.

![סקיצת הדשבורד](docs/dashboard-mockup.png)

## תכונות

- 📊 **דשבורד** עם מאזן, הכנסות, הוצאות ואחוז חיסכון
- 🍩 **פילוח הוצאות לפי קטגוריות** עם תרשים דונאט
- 📈 **מגמה חודשית** של הכנסות מול הוצאות
- 📉 **ממוצע הוצאה חודשי לכל קטגוריה**
- 🏷️ **סיווג אוטומטי** של תנועות לפי בית העסק + עריכה ידנית
- 🧾 **רשימת תנועות** עם חיפוש וסינון
- 📄 **ייבוא CSV** מדפי בנק / חברות אשראי (מנותח בתוך הדפדפן)
- 📱 **PWA** — ניתן להתקנה על מסך הבית של הטלפון
- 🇮🇱 ממשק בעברית מלא, תמיכת RTL, עיצוב מודרני

## הרצה מקומית

```bash
npm run install:all   # התקנת תלויות
npm run dev           # הרצת האפליקציה
```

פתח את **http://localhost:5173**. בפעם הראשונה לחץ **"טען נתוני דמו"** כדי לראות את
הדשבורד מלא, או ייבא קובץ CSV משלך.

## 🌐 פריסה חינמית (אתר אמיתי, נגיש מכל מקום)

מכיוון שזו אפליקציה סטטית, אפשר לארח אותה בחינם בכל שירות אירוח סטטי. הריפו כולל
קונפיגורציה מוכנה ל-Netlify ול-Vercel.

**Netlify (הכי פשוט):**
1. היכנס ל-[netlify.com](https://app.netlify.com) והתחבר עם GitHub
2. "Add new site" → "Import an existing project" → בחר את הריפו
3. ההגדרות נטענות אוטומטית מ-`netlify.toml` (build: `client`, publish: `dist`)
4. תוך דקה תקבל כתובת קבועה כמו `https://nova-finance.netlify.app`

**Vercel:** ייבא את הריפו ב-[vercel.com](https://vercel.com) — ההגדרות נטענות מ-`vercel.json`.

**Cloudflare Pages:** Build command `cd client && npm install && npm run build`, output `client/dist`.

לאחר הפריסה — פתח את הכתובת בטלפון, ו**התקן כאפליקציה**:
- **אייפון (Safari):** כפתור שיתוף → "הוסף למסך הבית"
- **אנדרואיד (Chrome):** תפריט ⋮ → "התקן אפליקציה"

> 💡 הנתונים נשמרים בנפרד בכל דפדפן/מכשיר (הם מקומיים). כדי להעביר נתונים בין מכשירים
> אפשר לייבא את אותו קובץ CSV בכל אחד מהם.

## 📱 גישה מהטלפון בלי לפרוס (דרך ה-WiFi)

אם אתה מעדיף לא לפרוס, אפשר להריץ במחשב ולגשת מהטלפון באותה רשת:
1. הרץ `npm run dev` — Vite ידפיס שורת **Network** (למשל `http://192.168.1.20:5173/`)
2. פתח את הכתובת הזו בדפדפן של הטלפון (שני המכשירים על אותה רשת WiFi)

## ייבוא נתונים מהבנק / כרטיס אשראי

1. היכנס לאתר הבנק או חברת האשראי
2. ייצא דף תנועות בפורמט **CSV** (או Excel ושמור כ-CSV)
3. באפליקציה לחץ **"ייבוא תנועות"** וגרור את הקובץ

הניתוח קורה כולו בדפדפן: זיהוי אוטומטי של עמודות תאריך/תיאור/סכום (עברית/אנגלית),
פורמט תאריך ישראלי (DD/MM/YYYY), וסיווג אוטומטי לקטגוריות.

## חיבור אוטומטי לבנק (אופציונלי, מתקדם)

אתר סטטי לא יכול לגרד נתונים מהבנק אוטומטית (גירוד דורש דפדפן אמיתי בשרת). למי שרוצה
זאת, הריפו כולל **שרת אופציונלי** בתיקיית `server/` עם אינטגרציה ל-
[`israeli-bank-scrapers`](https://github.com/eshaham/israeli-bank-scrapers), שניתן להריץ
מקומית בלבד:

```bash
npm run dev:server                                   # מריץ שרת + לקוח
npm --prefix server install israeli-bank-scrapers    # להפעלת הגירוד
```

> ⚠️ **אבטחה**: אם משתמשים בגירוד — פרטי ההתחברות לבנק מועברים לשרת המקומי בלבד
> ואינם נשמרים לדיסק. הרץ זאת רק במחשב האישי שלך. לעולם אל תפרוס את השרת הזה לאינטרנט
> עם פרטי בנק אמיתיים.

## מבנה הפרויקט

```
.
├── client/                  # האפליקציה (React + Vite + Tailwind + Recharts)
│   ├── public/              # manifest, service worker, אייקוני PWA
│   └── src/
│       ├── App.tsx
│       ├── api.ts           # שכבת נתונים מקומית (ללא שרת)
│       ├── lib/             # הלוגיקה: סיווג, ניתוח CSV, סטטיסטיקה, אחסון (IndexedDB)
│       └── components/
├── server/                  # שרת אופציונלי (גירוד בנק מקומי בלבד) - לא נדרש לאתר
├── netlify.toml             # קונפיגורציית פריסה ל-Netlify
└── vercel.json              # קונפיגורציית פריסה ל-Vercel
```

## טכנולוגיות

- **React 18, Vite, TypeScript, TailwindCSS, Recharts**
- **אחסון**: IndexedDB בדפדפן (ללא שרת, ללא תלות חיצונית)
- **PWA**: manifest + service worker להתקנה על מסך הבית
